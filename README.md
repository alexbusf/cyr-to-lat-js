# JS Transliteration

A lightweight JavaScript script for instant Cyrillic-to-Latin transliteration. Perfect for generating URL slugs and quick manual text conversion.

## Demo

Simply open the `index.html` file in any web browser to see it in action.

## Installation

Copy the `js/translit.js` or `js/translitweb.js` file into your project.

Include the script in your HTML file before the closing `</body>` tag:
```html
<script src="js/translit.js" defer></script>
